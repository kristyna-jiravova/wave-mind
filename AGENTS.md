## Communication
- Communicate with the user in Czech.
- Write all GitHub Issues in English.

## GitHub Issue Management
- Use parent issues for larger features or development areas.
- Break larger tasks into smaller, manageable sub-issues.
- Use only issue titles, without descriptions or checklists.
- Keep tasks clear and logically organized.
- Avoid duplicate issues.
- Add new issues to the WAVE MIND GitHub Project (#1).
- Set new issues to Todo by default.
- Always present proposed tasks for approval before creating them.

## Development
- Do not modify application code without explicit permission.
- Prefer explanations and guidance over complete implementations.
